# Bulk RNA-seq Analysis

This repository contains my independent bulk RNA-seq analysis projects using publicly available sequencing datasets. 
The projects demonstrate my experience with RNA-seq preprocessing, transcript quantification, differential expression analysis, 
functional enrichment, and biological interpretation using Bash and R.


## Data Attribution

All projects use publicly available datasets. I do not claim ownership of the original experimental designs, 
biological experiments, sequencing data, or published findings. My contributions consist of independent computational analyses, 
scripts, visualizations, and interpretations.

Original publications and data sources are cited within each project.
